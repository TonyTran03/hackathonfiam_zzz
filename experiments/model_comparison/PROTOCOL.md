# Frozen comparison protocol

Written before fitting or inspecting this experiment's results.

Purpose: compare algorithms under a shared objective and portfolio policy, not reproduce the team's existing performance claims. The team has already examined the historical test period, so this is a controlled historical comparison, not a new untouched holdout.

- Source: supplied 529,082-row characteristics panel; 147 features selected by the supplied CSV. No filing features or new external data.
- Target: original next-month excess return, unchanged and unclipped, for ALL models. This deliberately differs from the team's existing LightGBM-only demeaning/clipping. Conclusions apply to this common objective, not every possible LightGBM setup.
- Annual expanding training / preceding two-year validation windows from the competition, split by target month. Predict all rows regardless of whether future labels are present.
- Within each feature month, rank observed values to [-1,1]. Preserve those observed values identically across variants. Median variant fills missing ranks with that month's observed median rank; entirely missing columns become zero. Linear models use this filled table and training-only standardization.
- Models: OLS, Ridge, Lasso, Elastic Net (l1_ratio=0.5), LightGBM missing preserved, LightGBM median filled. Use original linear penalty grids and three original LightGBM configurations. All select hyperparameters by validation MSE on the SAME original target. LightGBM uses up to 3,000 trees, patience 50, fixed seed 2026, deterministic execution.
- Annual blend: within EACH annual fold, compare GBM-missing, GBM-filled, average linear, equal standardized average of linear and GBM-missing, and Ridge/GBM-missing blend by mean validation-month Spearman correlation. Apply only to that year's test forecasts. Save every choice.
- Missing-value ablation: additionally fit median-filled LightGBM with the SAME configuration and tree count selected for missing-preserved LightGBM. This controls for hyperparameter choice as well as observed feature values.
- Portfolio: reuse the supplied branch's price/size/available-risk screen, sector/size/beta residualization, inverse-volatility allocation, beta leg sizing, historical beta feedback, 100 stocks per leg, 200% gross, 30% internal net cap, 3-month smoothing and 2.5x retention buffer. No portfolio tuning. Correct smoothing to calendar months, so gaps do not silently lengthen its horizon. Apply exactly the same policy to all models. Keep the inherited position-weight rule; its nominal 2% cap is before leg rescaling and is not an enforced final cap.
- Return accounting: derive the source risk-free rate from same-month ret minus ret_exc and reconstruct raw forward returns from target plus next month's source RF. Use cash + sum(weight * (raw return - cash)) with TB3MS/1200 cash, equivalent to (1-net)*cash + sum(weight*raw). No assumption that source RF equals TB3MS. Missing outcomes do not remove positions: explicitly assume zero raw return and report missing exposure and adverse-scenario sensitivity.
- Costs: 0, 10, 20, 30, 50 basis points per dollar traded. Headline net result at 20 bps. Compute trading against prior positions drifted by stock returns and portfolio NAV after prior costs. Include initial entry; do not force terminal liquidation. Borrow fees and asymmetric financing not modeled.
- Metrics: prediction OOS R2 versus zero, mean monthly Spearman IC, monthly/yearly return series, CAGR, annualized information ratio vs cash+4%, Sharpe, market beta, drawdown including initial NAV, turnover, missing exposure, and trading limits. Market series is S&P 500 PRICE return from the supplied snapshot, not a total-return index.
- Uncertainty: paired circular 6-month block bootstrap of net monthly return differences, 2,000 draws, fixed seed. Interpret as descriptive uncertainty, not post-selection proof. No expanding search after viewing results.
