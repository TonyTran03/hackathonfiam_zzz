# Team models

Put model implementations here. A fitted model's `predict(X_test)` method should
return a one-dimensional array of predicted next-month excess returns, one per
input row in exactly the same order. It need not return features or outcomes.

Use `project_paths.py` for repository-relative data paths. Run project code from
the repository root so `models`, `tests`, and `project_paths` are importable.

`penalized_linear_hackathon.py` is a supplied reference demo with placeholder
paths and an older sample-data schema. It is not the team's implemented model.
